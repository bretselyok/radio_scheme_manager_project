# radio_scheme_manager_project
# АС управления разработкой радиоэлектронных схем

Учебный проект для ВКР по теме: **«Управление разработкой автоматизированной системы разработки радиоэлектронных схем»**.

Проект можно открыть в PyCharm как обычную папку Python-проекта. Приложение сделано как локальная клиент-серверная система.
- сервер API: `http.server` + SQLite;
- клиент: настольный интерфейс Tkinter;
- база данных: SQLite, создается автоматически в `data/radio_schemes.db`;
- отчеты: формирование DOCX, XLSX и SVG-схем в папку `exports`;
- внешние библиотеки для запуска не требуются.

## Основной функционал

- авторизация и роли пользователей;
- панель администратора;
- личный кабинет пользователя;
- панель управления проектом;
- управление проектами разработки схем;
- учет стейкхолдеров;
- карточки радиоэлектронных схем и версий;
- визуальный редактор схем: условные обозначения, проводники, сохранение в БД, экспорт SVG;
- справочник элементной базы;
- перечень элементов схемы/BOM;
- требования к системе и схемам;
- план работ, исполнители, сроки, прогресс;
- испытания и контроль качества;
- риски проекта и оценка вероятности/влияния;
- документы проекта с выбором файлов из файловой системы;
- заявки на изменения;
- экономические параметры, расчет TCO/NPV/ROI/окупаемости;
- глобальный поиск;
- справка по системе;
- формирование отчетов DOCX/XLSX.

# Руководство пользователя

## Автоматизированная система управления разработкой радиоэлектронных схем

### Системные требования

- Операционная система: Windows / Linux
- Python 3.10 или выше
- Среда разработки PyCharm (опционально, для запуска из исходников)
- Дополнительные библиотеки не требуются (используются только встроенные модули: Tkinter, sqlite3, unittest, zipfile и др.)

---

### Установка и запуск

#### Вариант 1: Запуск из исходного кода (рекомендуется для разработки)

1. Скачайте или клонируйте репозиторий проекта.
2. Откройте папку проекта в PyCharm (или другом редакторе).
3. Запустите файл `main.py`.
4. При первом запуске автоматически создастся база данных SQLite (`data/radio_scheme.db`) и заполнится демонстрационными данными.

#### Вариант 2: Запуск исполняемого файла (для пользователей)

- Если вы используете готовую сборку `RadioSchemeManager.exe`, просто запустите этот файл.
- База данных и файлы отчетов будут создаваться в папке с программой.

---

### Начало работы

#### Вход в систему

После запуска откроется окно авторизации. Используйте одну из предустановленных учётных записей:

| Логин          | Пароль        | Роль                     |
|----------------|---------------|--------------------------|
| `admin`        | `admin123`    | Администратор            |
| `manager`      | `manager123`  | Руководитель проекта     |
| `engineer`     | `engineer123` | Инженер-схемотехник      |
| `controller`   | `control123`  | Специалист контроля качества |

Введите логин и пароль, нажмите **Вход**.

#### Главное окно

После авторизации откроется главное окно приложения. Верхнее меню содержит разделы:

- **Проект** – управление проектами, требованиями, задачами, рисками, документами.
- **Схемотехника** – работа со схемами, элементной базой, BOM.
- **Управление** – пользователи и роли (только для администратора), журнал действий, настройки.
- **Отчеты** – формирование выходных документов (DOCX, XLSX).
- **Справка** – руководство пользователя, информация о системе.

Строка состояния внизу показывает имя текущего пользователя и его роль.

---

### Роли пользователей

Система разграничивает доступ в зависимости от роли:

| Роль                     | Что можно делать                                                                                                                                          |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Администратор**        | Полный доступ: управление пользователями, ролями, настройками, просмотр журнала действий, резервное копирование (вручную).                                 |
| **Руководитель проекта** | Создание и управление проектами, требованиями, задачами, рисками, экономическими данными; просмотр схем и BOM; формирование отчётов.                    |
| **Инженер-схемотехник**  | Разработка схем (визуальный редактор), ведение элементной базы, формирование BOM, загрузка документов.                                                    |
| **Контролёр качества**   | Просмотр схем и BOM, создание испытаний и замечаний, ведение рисков, формирование отчётов. **Не может редактировать графическую структуру схемы**.       |

### Работа с проектом

1. Перейдите в **Проект -> Проекты**.
2. Нажмите **Добавить** – заполните поля: код, название, заказчик, сроки, бюджет.
3. Для созданного проекта можно добавить:
   - **Требования** (раздел «Требования»)
   - **Задачи** (раздел «Задачи»)
   - **Риски** (раздел «Риски»)
   - **Документы** (прикрепить файлы, например ТЗ, протоколы)

---

### Разработка схемы

#### Создание карточки схемы

- Перейдите в **Схемотехника -> Схемы**.
- Нажмите **Добавить**: укажите код схемы (например, `SCH-PSU-001`), тип, версию, статус («Черновик»), выберите проект.
- Сохраните карточку.

#### Визуальный редактор

1. Выберите схему из списка и нажмите **Редактор** (доступно для ролей `engineer` и `admin`).
2. Откроется графический редактор:
   - **Выбор символа** – резистор, конденсатор, диод, источник питания, земля, микросхема и др.
   - **Добавление элемента** – выберите тип, затем кликните на поле редактирования.
   - **Перемещение элемента** – захватите элемент мышью.
   - **Проводники** – нажмите кнопку «Проводник», затем кликните начальную и конечную точки.
   - **Удаление** – выделите элемент или проводник, нажмите «Удалить».
3. После завершения нажмите **Сохранить** – структура схемы (узлы и проводники) запишется в базу данных.
4. Для экспорта в SVG нажмите **Экспорт SVG**.

#### Перечень элементов (BOM)

- Перейдите в **Схемотехника → BOM**.
- Выберите схему из списка.
- Добавляйте позиции: укажите компонент (из справочника), позиционное обозначение (`R1`, `C2` и т.д.), количество.
- Система автоматически рассчитает стоимость позиции и общую сумму.

---

### Управление качеством и испытаниями

Для роли **Контролёр качества** доступен раздел **Управление -> Испытания**.

1. Нажмите **Добавить**.
2. Выберите проект, схему, требование (из требований проекта).
3. Укажите метод проверки, ожидаемый результат, статус (`Пройден`, `Не пройден`, `Не запускался`).
4. В поле «Замечания» можно зафиксировать выявленные недостатки.

---

### Формирование отчётов

Перейдите в **Отчёты**.

- **Паспорт проекта (DOCX)** – выберите проект, нажмите «Сформировать». Отчёт содержит цели, задачи, требования, риски, бюджет.
- **Перечень элементов (XLSX)** – выберите схему, нажмите «Сформировать». Создаётся таблица BOM с позициями, количеством, ценой.
- **Экономическая эффективность** – рассчитывает NPV, ROI, срок окупаемости по введённым данным.
- **Сводка руководителя** – отчёт по всем проектам, задачам, рискам.

Все отчёты сохраняются в папку `exports/` в форматах `.docx` или `.xlsx`.

---

### Администрирование

Доступно только для роли `admin` в разделе **Управление -> Пользователи**.

- Просмотр списка пользователей.
- Добавление нового пользователя (логин, пароль, ФИО, роль).
- Редактирование и удаление.

В разделе **Журнал действий** фиксируются все значимые операции (вход, создание, изменение, удаление, сохранение схемы).

---

### Поиск и справка

- **Поиск** – глобальный поиск по проектам, схемам, компонентам, требованиям.
- **Справка** – краткое руководство пользователя (открывается в отдельном окне).

---

### Экспорт схемы в SVG

В визуальном редакторе нажмите **Экспорт SVG**. Будет создан файл `schematic_<id>_<timestamp>.svg` в папке `exports/`. Его можно вставить в отчёт или просмотреть в любом браузере.
